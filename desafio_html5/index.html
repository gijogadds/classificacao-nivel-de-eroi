HTML5

Origem: Wikipédia, a enciclopédia livre.

HTML5 (Hypertext Markup Language, versão 5) é uma linguagem de marcação para a World Wide Web e é uma tecnologia chave da Internet, originalmente proposto por Opera Software. É a quinta versão da linguagem HTML.

História

O Web Hypertext Application Technology Working Group (WHATWG) começou a trabalhar no novo padrão em 2004, numa época em que o World Wide Web Consortium (W3C) estava focando desenvolvimentos futuros em XHTML 2.0, e o HTML 4.01 não tinha sido atualizado desde 2000.

Em 2009, o W3C admitiu que a direção do XHTML 2.0 estava errada e decidiu descontinuar o desenvolvimento desta especificação. Com o esforço focado agora inteiramente no HTML5, ele foi formalmente publicado como Recomendação pelo W3C em outubro de 2014.

Novos Recursos e Semântica

O HTML5 introduz elementos e atributos que refletem o uso típico em sites modernos. Alguns deles são novos elementos semânticos substitutos para usos comuns de <div> genérico:

  • <article>: Representa uma composição independente, de forma que faça sentido ser lida fora de contexto.
  • <section>: Representa uma seção genérica de um documento ou aplicativo, servindo para organizar o conteúdo.
  • <nav>: Representa uma seção do documento destinada à navegação com links principais.
  • <header> e <footer>: Representam, respectivamente, o cabeçalho e o rodapé da página ou de seções independentes.
  • <aside>: Representa uma parte da página com conteúdo marginalmente relacionado (como uma barra lateral ou caixa de informações).

APIs do HTML5

Além da marcação avançada com novas tags e foco total em acessibilidade, o HTML5 especifica APIs de scripting que podem ser usadas com JavaScript, tornando a web uma plataforma poderosa para aplicações ricas. Algumas destas APIs incluem:

Geolocalização

Permite compartilhar a localização física do usuário com o aplicativo web de forma segura, com o consentimento do utilizador.

Canvas e WebGL

Permite renderização dinâmica via hardware, por script, de formas 2D e modelos 3D diretamente no navegador sem uso de plugins externos.

Armazenamento Web

Fornece mecanismos como o LocalStorage e SessionStorage para armazenar pares chave/valor de forma mais rápida e segura que os tradicionais cookies.
